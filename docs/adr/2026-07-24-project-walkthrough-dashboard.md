# ADR: 프로젝트 Walkthrough 대시보드

- 상태: Accepted
- 날짜: 2026-07-24
- 범위: 백엔드 기능 설명과 로컬 시연 화면

## 배경

백엔드 코드는 API, 서비스, repository, gateway, 테스트 파일을 직접 읽어야 전체 흐름을 이해할 수 있습니다. 따라서 프로젝트를 처음 보는 사람이 구현 목적과 처리 순서를 빠르게 파악할 수 있는 별도 설명 화면이 필요합니다.

## 결정

- 대시보드의 기본 탭을 프로젝트 가이드로 두고 핵심 기능을 시나리오 단위로 제공합니다.
- 결제 생명주기, 승인 멱등성, 웹훅 보정, 트랜잭션 아웃박스 네 가지 시나리오를 선택할 수 있습니다.
- 시나리오 실행은 실제 외부 PG가 아니라 localhost 백엔드 API를 호출합니다.
- 각 단계에 endpoint, 상태, traceId, 운영상 의미를 시간순으로 표시합니다.
- 개요, Payment Demo, 운영 대시보드 탭은 설명·직접 조작·운영 지표 확인 용도로 분리합니다.

## 선택 이유

정적인 아키텍처 그림만 제공하면 실제 요청과 응답의 관계를 확인하기 어렵고, 코드 링크만 제공하면 프로젝트를 처음 보는 사람이 진입하기 어렵습니다. 실제 로컬 API 호출 결과를 단계별 로그로 보여주는 방식을 선택해 설명과 재현을 함께 제공했습니다.

## 제한

- 시나리오 데이터는 로컬 DB에 생성되므로 반복 실행 시 샘플 결제가 누적될 수 있습니다.
- 외부 Toss API, Kafka, 유료 모니터링 서비스의 실시간 상태를 보여주는 화면은 아닙니다.
- 운영 환경에서는 내부 운영 endpoint와 시연용 token을 별도 인증 체계로 교체해야 합니다.
