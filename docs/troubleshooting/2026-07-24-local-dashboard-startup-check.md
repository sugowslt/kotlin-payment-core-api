# 로컬 대시보드 기동 확인 명령 시간 초과

- 발생일: 2026-07-24
- 영향: 기동 확인 명령만 종료되지 않았으며 애플리케이션 기능 장애는 확인되지 않았습니다.

## 증상

백엔드 `8080`과 Vue 개발 서버 `5173`을 백그라운드로 실행한 뒤 두 endpoint를 최대 12회 반복 조회하는 PowerShell 확인 명령이 40초 제한에 걸렸습니다.

## 확인 과정

1. 서버 프로세스가 종료되었는지 확인했습니다.
2. `8080`, `5173` 수신 포트 상태를 확인했습니다.
3. 두 주소를 개별적으로 짧은 timeout으로 다시 조회했습니다.

재확인 결과는 다음과 같습니다.

- `http://127.0.0.1:5173`: HTTP 200
- `http://127.0.0.1:8080/api-docs`: HTTP 200

## 원인 판단

애플리케이션이나 대시보드의 오류 로그가 아니라, 두 endpoint를 순차적으로 반복 조회하는 검증 명령의 전체 실행 시간이 제한 시간을 초과한 상황으로 판단했습니다. 서버 프로세스는 계속 실행 중이었고 개별 응답도 정상이었습니다.

## 해결 방법과 선택 이유

반복 횟수를 무작정 늘리거나 서버를 재시작하지 않고, 프로세스·포트·개별 HTTP 응답을 분리해 확인했습니다. 이 방법을 선택한 이유는 실제 서비스 상태와 검증 스크립트의 종료 문제를 구분하면서, 불필요한 재시작으로 현재 상태를 바꾸지 않기 위해서입니다.

## 재발 방지

- 서버 기동 확인은 전체 polling 명령의 timeout과 endpoint별 timeout을 분리합니다.
- 기동 확인 실패 시 프로세스 종료 여부와 개별 endpoint 응답을 먼저 확인합니다.
- 본 검증에서는 외부 네트워크, 실결제 API, 유료 서비스에 접근하지 않았습니다.
