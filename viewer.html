kotlin-payment-core-api — 시스템 개요

로컬에서 실행 가능한 결제 API. 상태 머신, 커서 기반 페이지네이션, traceId 추적.

아키텍처

Client
  -> TraceIdFilter (X-Trace-Id generate/echo)
  -> PaymentController
  -> PaymentService
  -> PaymentRepository (JPA/H2 or MySQL)
  -> GlobalExceptionHandler

성능 비교

엔드포인트

POST /api/payments
GET /api/payments
GET /api/payments/{id}
DELETE /api/payments/{id}
